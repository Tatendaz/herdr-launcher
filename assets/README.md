# Third-party artwork

The ram in `icon.svg` and `icon-1024.png` is the herdr project's logo,
rebuilt from the SVG assets served by [herdr.dev](https://herdr.dev/) in the
site header's colors (`#1a1a18` on `#f5f3ee`). It belongs to the
[herdr project](https://github.com/ogulcancelik/herdr) and is **not** covered
by this repository's MIT license. Permission for its use as this launcher's
icon was requested from the herdr team on 2026-07-18.

Forks that target another tool must replace both files, then rebuild with
`./build.sh`.
